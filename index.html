The Sovereign Retro Preservation Hub

A native macOS 13+ application engineered to organize, enhance, and launch classic games across 35 platforms with an offline 67,000+ title catalog and zero cloud tracking.

Download for macOS (Apple Silicon) View on GitHub ★
$ brew tap NightKnight24/omnivault && brew install --cask omnivault
⚡

100% Native & Standalone

Built with Swift and Metal for macOS Apple Silicon. Zero Python, uv, or terminal prerequisites for end users. Just download, drag to Applications, and play.

📚

67,000+ Offline Title Catalog

Ships with an offline encyclopedia of metadata, release dates, box art, and lore for 35 classic consoles—from NES, Genesis, and PS1 to GameCube, PS4, and Switch.

🎮

Universal Quick Menu

Background controller monitoring triggers an instant overlay over any running emulator via Home, Select+Start, or L3+R3 to manage save states and shaders.

🛡️

Bring Your Own Sources (BYOS)

Zero copyrighted ROMs are bundled or hosted. OmniVault is 100% legally compliant, connecting to your personal SSD, NAS, or public archive collections.

💾

Save-State Snapshot Engine

Time-machine backups automatically snapshot save states after boss fights or long sessions, preventing accidental file corruption or overwrite.

🧠

Embedded Local Neural Copilot

OmniAI runs local quantized LLMs on Apple Silicon Metal GPUs. Ask for level walkthroughs, secret unlock codes, or save-file diffs completely offline.
